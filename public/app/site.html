Trạng thái lead

    Gói Pro trở lên. Nhập tên miền, bấm Lưu, sau đó thêm bản ghi DNS theo hướng dẫn bên dưới.

    Theo dõi & quảng cáo

    Sự kiện chuyển đổi (Lead / generate_lead / SubmitForm) được tự gửi khi khách điền form thành công.

    Thông báo khi có lead mới

    Tạo bot qua @BotFather.
    Slack → Apps → Incoming Webhooks → Add to channel, dán URL hooks.slack.com.
    Cài đặt kênh → Tích hợp → Webhook → Sao chép URL webhook.
    Hướng dẫn kết nối Google Sheets
    1. Mở Google Sheet → Tiện ích mở rộng → Apps Script, dán đoạn mã dưới đây rồi Lưu.
    2. Triển khai → Tùy chọn triển khai mới → Loại: Ứng dụng web; Thực thi với tư cách: Tôi; Ai có quyền truy cập: Bất kỳ ai.
    3. Sao chép URL dạng https://script.google.com/macros/s/…/exec và dán vào ô trên.
    function doPost(e) {
  var lock = LockService.getScriptLock();
  lock.waitLock(10000);
  try {
    var row = JSON.parse(e.postData.contents);
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
    var headers = sheet.getLastColumn()
      ? sheet.getRange(1, 1, 1, sheet.getLastColumn()).getValues()[0]
      : [];
    Object.keys(row).forEach(function (k) {
      if (headers.indexOf(k) === -1) headers.push(k);
    });
    sheet.getRange(1, 1, 1, headers.length).setValues([headers]);
    sheet.appendRow(headers.map(function (h) {
      return row[h] === undefined ? '' : row[h];
    }));
    return ContentService.createTextOutput('ok');
  } finally {
    lock.releaseLock();
  }
}

    Chống spam & chất lượng lead

    Lead trùng vẫn được lưu nhưng không gửi thông báo lại. 0 = tắt.
    Turnstile (tùy chọn) thêm ô xác minh “không phải robot” vào mọi biểu mẫu. Khai báo tên miền của website trong Cloudflare. Lead bị nghi là spam được lưu ở bộ lọc “Spam”, không gửi thông báo và không tính vào hạn mức.
